# windows-utilities

A collection of small utilities for Windows.

| Utility | Description |
|---|---|
| [auto-theme-switch](auto-theme-switch/README.md) | Switches Windows to dark mode at sunset and light mode at sunrise, with a manual toggle. |

Tools that grew into their own repositories:

- [one-task](https://github.com/neuralrift/one-task): a terminal todo that shows one task at a time (`t`).
- [fuzzy-files](https://github.com/neuralrift/fuzzy-files): a terminal file finder and manager built on fd and fzf (`f`).
